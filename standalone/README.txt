Codex 自动继续 —— 独立版（不用装 DSH）
======================================

它能干什么
----------
Codex（ChatGPT 桌面应用）被上游 429 卡住、或者额度用尽停下来的时候，
它会每隔 5 分钟替你看一眼，卡住了就替你点「继续」。
你切到别的会话去了，它会把跑任务那个会话找回来；
同时开了好几个任务，它每 10 分钟挨个翻一遍看看有没有卡住的。

怎么用
------
1. 双击「启动 Codex 自动继续.vbs」——右下角会出现一个盾牌图标，说明它起来了。
   （没有任何窗口弹出来是正常的，它就躲在托盘里。）
2. 想让它开机自己起来：双击「安装开机自启.vbs」，只要一次。
3. 想让它停下：双击「停止.vbs」。

想改设置
--------
用记事本打开 config.json，改完保存，然后「停止.vbs」再「启动」。

  intervalSeconds       多少秒看一眼，默认 300（5 分钟）
  maxAttempts           最多替你点几次，0 = 不限，默认 0
  windowKeyword         认哪个窗口，默认 ChatGPT；Codex 换名字时改这里
  scanRecent            额外翻几个会话，默认 5；填 0 就只盯当前会话
  watchSessions         额外固定盯哪几个会话，标题用分号隔开
  scanIntervalSeconds   多久翻一次别的会话，默认 600（10 分钟）
  notify                救不回来时要不要弹右下角通知，默认 true
  paused                填 true = 暂停（只偶尔看一眼，不动作）

注意
----
- 它不改 Codex 的任何文件，只是像人一样"点按钮"。
- 点的时候不会抢你的键盘焦点，也不会移动鼠标，可以一边用电脑一边跑。
- 它只在 Codex 空闲（没在生成）的时候才点，不会打断正在跑的任务。
- 重复双击「启动」不会起两个：第二次会说"已经有一个在跑了"。
- 「停止.vbs」只会停掉这个工具的托盘进程，不会动你别的 PowerShell 窗口。
- 日志在 data\nudge.log，出问题先看这个。

卸载
----
先双击「取消开机自启.vbs」，再「停止.vbs」，然后把整个文件夹删掉就行。
（它不写注册表，也不往别的地方放东西。）
